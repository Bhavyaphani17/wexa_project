# StockFlow – Inventory Management System

A simple SaaS based inventory management application developed as part of the Software Developer Intern assessment at Wexa AI.

## Project Overview

StockFlow helps users manage their products, monitor stock quantities, and identify low-stock items through a simple dashboard.

## Planned Features

- User Signup and Login
- Organization based data management
- Product Management (CRUD)
- Inventory and Stock Tracking
- Dashboard with Inventory Summary
- Low Stock Alerts
- Configurable Stock Threshold
